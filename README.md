# Framewright

An open-source, fully offline desktop app for residential design: walls, openings, catalog objects, automatic roofs/framing/foundations/stairs, linked plan/elevation/section/3D views, materials lists, and construction documents. Windows and macOS.

Status: **M1a** (secure offline app shell). Design: [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md). Build and install: [docs/BUILDING.md](docs/BUILDING.md). Bundled assets: [ASSETS.md](ASSETS.md).

```sh
npm ci
npm run dev
```
